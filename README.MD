# Welcome to your Expo app 👋

This is an html, css, and typescript website. It's designed for my wedding that is happening next month
which is on Aapril 11th

## Get started

1. Start by typing npm run dev to pull up website
2. Click the Link and it'll take you to the site

## database operations

1. to list RSVPs `node src\scripts\list.ts`
2. to remove RSVPs `node src\scripts\delete.ts`
3. to update RSVPs `node src\scripts\update.ts`


## Get a fresh project

When you're ready kill the treminal and typ npm run dev again
